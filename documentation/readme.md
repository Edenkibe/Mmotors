# Mmotors

## Présentation du projet

Mmotors est une application web développée avec Django et Python.

Elle a pour objectif: vente et location de vehicule en ligne.

## Technologies utilisées

-Python
- Django
- HTML / CSS
- JavaScript
- Mysql
-stripe
-yousign
-celery beat et worker
-redis 
-recaptcha
-smtp gmail
-mysqlclient
-weasyprint etc..

## Fonctionnalités principales

- Gestion des utilisateurs.
- Gestion des demandes.
- Acheter une vehicule en ligne
-la location de vehicule enligne
